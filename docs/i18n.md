# Web Box internationalization

## Initialization and persistence

`src/i18n/index.ts` synchronously initializes i18next and react-i18next with bundled JSON before React renders. `src/i18n/config.ts` reads only `web-box:language`: `en` and `zh-CN` are accepted; absent, invalid, or inaccessible storage falls back to `en`. No browser, operating-system, location, URL, or remote detection is used. Changes persist only this dedicated key; restricted storage retains the active language in memory. Existing theme behavior and its `web-box-theme` key remain independent.

The existing HashRouter and routes remain unchanged, including the existing legacy category redirects. Language switching calls `changeLanguage` without navigation, refresh, or remount. Route scrolling/focus effects run only on navigation; translated document title, description, and HTML language update separately.

## Translation resources

Both `src/i18n/resources/en/` and `src/i18n/resources/zh-CN/` contain:

- `common.json`: homepage, actions, status, accessibility, about, privacy, footer, and metadata.
- `navigation.json`: main navigation, breadcrumbs, and footer navigation.
- `categories.json`: seven local category names, short names, and descriptions.
- `resources.json`: overview, eight external category names/descriptions, resource descriptions, counts, and empty states.
- `tools.json`: seven existing planned-tool names and descriptions.

Catalog keys follow stable IDs (`text-content.name`, `ext-dev.description`, `items.mdn.description`), with `keySeparator: false`. English registry metadata is retained for existing consumers; display components resolve copy from the translation resources through `useCatalogTranslation`, which uses the standard `useTranslation` API. IDs, associations, brands, URLs, and tool paths stay stable. Counts use i18next interpolation and plural rules.

`types.ts` augments i18next from the English resource shape. The catalog helper confines dynamic ID-to-key assertions to one module; automated completeness checks validate those IDs against both languages. Development startup warns about incomplete Chinese translations; missing keys also produce a development warning. Chinese falls back to English.

## Language toggle

`LanguageSwitcher.tsx` is a single native 48px button beside the theme button, visible at all breakpoints. It directly toggles `en` and `zh-CN` through the existing i18next instance; it has no menu or local language state. The square button displays only the Lucide Languages icon. Its title tooltip and accessible action label are “Switch to Chinese” in English and “切换为英文” in Chinese. Native button semantics support Tab, Enter, and Space. Existing Carbon hover, active, and focus styles are inherited; persistence stays in the shared i18n initializer.

## Coverage

Home, main/mobile/category navigation, breadcrumbs, seven category pages, seven planned-tool pages/cards, resource overview, eight resource category pages, resource cards, empty states, 404, about, privacy, footer, theme tooltips, accessible labels, and document metadata are translated. The current site has no functional tool forms, dialogs, favorites, recent-history feature, or asynchronous loading/error flow; these features were not added.
